# Context inventory

Record only verified, task-relevant facts.

| Need | Evidence to capture | Home |
| --- | --- | --- |
| everyday command or boundary | command output, policy, or owner confirmation | main guide |
| architecture or decision | source path, owner, and revision date | routed context |
| repeated procedure | task samples and measured omission or quality issue | optional workflow |
| deterministic requirement | executable check and failure condition | script or test |

For a profile change, record baseline and enabled-profile task samples, model/runtime, prompts, success criteria, errors or omissions, and estimated context tokens. Keep profiles disabled until explicitly enabled; do not claim improvement from static size alone.
