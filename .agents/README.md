# Codex Skill Discovery

This directory is the official Codex repo-scoped skill location for projects generated by dev-template.

- `.agents/skills/` mirrors `.ai/skills/` so Codex can auto-discover shared project skills.
- `.ai/skills/` remains the provider-neutral skill source of truth.
- `.claude/skills/` is the Claude Code slash-command skill link.
- `.codex/skills/` is a compatibility skill link for tools that still look under `.codex/`.
- Add shared skills under `.ai/skills/`; the provider paths are discovery views, not separate sources.

Local agent runtime state should live under `.agents/local/`, `.agents/tmp/`, `.agents/sessions/`, or `.agents/logs/`, which are gitignored.
