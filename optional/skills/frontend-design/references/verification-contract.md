# Browser verification contract

Use the project-provided command and a route or fixture that represents the brief. Record enough evidence for another maintainer to reproduce the observation.

```md
## Evidence report
- Revision and changed files:
- Command and result:
- Browser/screenshot command or path:
- Route, viewport, content fixture, and interaction exercised:
- Observed result against the brief:
- Keyboard, focus, labels, contrast, motion, or responsive checks required by project standards:
- Unverified behavior and reason:
```

Report example form: “At the project-specified narrow viewport, the supplied empty-content fixture retained the documented primary action. Screenshot location and command are recorded above.” Do not claim a check that was not performed.
